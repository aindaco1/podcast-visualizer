# Podcast Visualizer 1.3.4

Status: released on September 23, 2026 (build 27). Public artifacts, the
installed 1.3.3-to-1.3.4 update, and the signed-app synthetic transcript workflow
passed verification. Workflow acceptance completed after publication.

New transcript approvals join short dependent fragments such as “Please” and
“slight.” using local continuation rules. Bounded look-ahead avoids filling one
cue in a way that strands a short ending such as “clear.” The existing source
words, speaker assignments, sentence boundaries and readability limits remain
protected. Earlier approved revisions open unchanged; only new approvals use
`lightly-cleaned-verbatim+dialogue-reflow-v2`.

The app still uses local FluidAudio 0.15.5 and six-boundary Apple Intelligence
requests. Speech recognition, chapter-generation prompts and models are
unchanged. Real media and project data remain on the Mac.

## Validation and limits

- The [fragment investigation](../testing/fragment-reflow-investigation.md)
  replayed the saved thirteen-cue synthetic review locally: five output cues
  instead of seven, all words preserved and the three isolated fragments joined.
  This is bounded regrouping; one earlier cue still ends in “the.” It is not a
  claim of perfect phrase segmentation or general podcast quality.
- Timed Text 0.11.2 versions the grouping policy. Read compatibility covers
  pre-reflow and v1 policies without changing stored data. Application rollback
  restores the previous gitlink and version; 1.3.3 cannot open new v2 approvals.
  Keep the original project or pre-upgrade revision when evaluating rollback.
  Platform is pinned to `917287cfe55444f7633be06af0f54579825849ba`.
- The [reviewed Jev suite](../testing/jev-suite-review.md) combines exact local
  structure checks with synthetic-only semantic judgments. Final reviewed
  evidence has zero exact failures, 18/20 correct semantic controls and 25/28
  passing generated candidates. Two accepted title controls were false failures;
  a vague generated chapter title was correctly rejected. The suite deliberately
  exits 1 and remains advisory. All transcript meaning checks passed. Neither
  questions nor thresholds were weakened to make the report green.
- Runtime fragment regressions, immutable-revision compatibility and release
  gates are checked independently of that known judge limitation. Jev tooling,
  provider credentials and evaluation reports are not bundled in the app.
- Delta base: public 1.3.3 ZIP, SHA-256
  `c01ea893f9b33a6ca248f7be4e8680206516e959c9b5adee0624d312c7aef1f4`.
- Local gates passed: 226 Node tests (three opt-in skips), 131 Swift app tests,
  one sidecar test, 27 Python tests, dependency audit, secret scan, workflow
  lint and whitespace checks. Both native products built for arm64. Node
  coverage was 76.24% lines, 77.48% branches and 85.42% functions.
