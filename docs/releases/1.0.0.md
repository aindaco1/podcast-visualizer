# Podcast Visualizer 1.0.0

The first stable Podcast Visualizer release packages the complete local-first
workflow as a native Apple Silicon macOS app.

## Highlights

- Create a project from local audio or reopen an existing project after
  relaunching the app.
- Follow accurate progress through transcription, alignment, and rendering.
- Review long transcripts in a dedicated tab; edit text, replace repeated
  terms, merge cues, and add, merge, rename, or delete speakers.
- Customize podcast and organization names, a local PNG logo, and speaker
  labels in rendered lines.
- Export 16:9, square, and vertical videos as opaque H.264, compact HEVC alpha,
  or ProRes 4444 alpha.
- Continue automatically through stages that require no human decision while
  keeping transcript and speaker approval mandatory.
- Check manually for cryptographically signed updates from GitHub Releases.

## Requirements

- Apple Silicon Mac
- macOS 15.0 or later
- A verified local Parakeet v3 Core ML model
- The pinned English alignment model, imported or explicitly downloaded in the
  app

Podcast media, transcripts, model inputs, and review data remain on the Mac.
Model downloads are never implicit. The release DMG and Sparkle ZIP are signed
with Developer ID, notarized by Apple, and accompanied by checksums, an SBOM,
build metadata, and notarization evidence.
