# Podcast Visualizer 1.0.6

Podcast Visualizer 1.0.6 fixes transcript Save and Approve for older projects
and adds a conservative, local post-approval dialogue reflow. Transcript words,
acoustic speaker evidence, and prior immutable revisions remain authoritative.

## Transcript review compatibility

Saving or approving a transcript no longer fails when an older project's edit
lineage has no base transcript revision. Native review edits use the version 4
contract, while the CLI continues to accept version 3 edits and transcripts
created before revision lineage was introduced.

## Dialogue reflow

After approval, Podcast Visualizer can combine short adjacent cues from the
same acoustic speaker when the result stays within strict pause, duration, word,
and character limits. It never rewrites transcript words, never infers a new
speaker identity from text, and never joins cues across an acoustic speaker
boundary. The transformation produces a new immutable transcript revision.

On macOS 26 or later, supported Apple Silicon Macs may use Apple's on-device
Foundation Models framework as a constrained boundary advisor. The model only
chooses **Join** or **Keep** for cue pairs already permitted by the deterministic
policy. Model unavailability, refusal, timeout, or invalid output falls back to
the deterministic result and does not block approval.

Parakeet remains the local speech-recognition model; it is not used as a
language model. Media, transcripts, model inputs, and review data stay on the
Mac, and this release adds no cloud inference path.

## Distribution

The app remains self-contained for Apple Silicon Macs running macOS 15 or
later. The optional Foundation Models advice requires macOS 26 and available
Apple Intelligence models; all other functionality and the deterministic
reflow work without it. The GitHub release includes the signed and notarized
app archive and DMG, signed Sparkle metadata and delta update, checksums, SBOM,
build metadata, and notarization evidence.
