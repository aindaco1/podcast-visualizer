# Podcast Visualizer 1.2.2

Podcast Visualizer 1.2.2 checks for signed updates automatically at every app
launch while keeping installation under the user's control.

## Quiet launch checks

Immediately after Sparkle starts, the app performs one background check against
the public signed GitHub appcast. The check is silent when Podcast Visualizer is
current. When a newer release is available, Sparkle presents its standard
update prompt so the user can review, defer, or install it.

The top-right **Check for Updates…** action remains available as a manual
fallback. Automatic downloading and installation remain disabled.

## Privacy and integrity

Sparkle system profiling is disabled. Update checks do not include podcast
media, paths, transcripts, speaker or review data, model inputs or outputs,
projects, renders, diagnostic reports, or raw helper streams.

Every accepted appcast, update archive, and binary delta remains bound to the
Podcast Visualizer Ed25519 key. Release artifacts retain Developer ID signing,
Apple notarization and stapling, checksums, SBOM, build metadata, and provenance
attestation. The updater delta for this release is generated from the verified
1.2.1 update archive.
