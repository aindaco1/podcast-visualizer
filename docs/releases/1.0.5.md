# Podcast Visualizer 1.0.5

Podcast Visualizer 1.0.5 is a maintenance update for model setup, portable
project media, and reliable transcription progress. Project, transcript,
render, and model formats do not change.

## Models interface

The Models card no longer exposes the verbose Automatic Search Locations list
or folder-management controls. It continues to check persistent app-owned
storage and Downloads automatically, and each missing model retains explicit
verified **Import Existing…** and pinned **Download** actions.

## Project-owned media

Project initialization copies selected audio or audio-bearing video into the
new project's immutable `source/original.*` path. Saving branding likewise
validates and copies a PNG into its hash-named `branding/assets/` path. The app
now says when those copies occur and keeps its sandbox access lease alive until
the operation succeeds. Tests delete both originals and then reload and process
the project-owned copies.

## Speech progress

Speech progress now travels over inherited descriptor 3 instead of standard
output. FluidAudio diagnostics remain ordinary diagnostics and can no longer
be interpreted as progress JSON. Both diagnostic and protocol streams remain
bounded; a successful sidecar must emit at least one valid sequenced progress
event, and non-finite progress updates are ignored without creating sequence
gaps.

The release workflow rebuilds the speech sidecar from the reviewed tag with the
packaged Node runtime before validating and assembling the app, so the shipped
binary cannot lag behind its source. Automated coverage includes descriptor
separation, output bounds, missing and non-finite progress, release-step order,
project media independence, branding asset independence, and the existing
runtime-manifest verification.
