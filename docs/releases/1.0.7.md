# Podcast Visualizer 1.0.7

Podcast Visualizer 1.0.7 is a focused workflow and Transcript Review safety
update. It keeps transcript editing predictable and gives users the final say
before compute-intensive rendering begins.

## Safer Transcript Review search

Find and Replace now keeps keyboard focus in the active search or replacement
field while matches are highlighted and navigated. Waiting between keystrokes
and then continuing a query no longer redirects typing into a selected
transcript cue or replaces cue text.

Workflow stages now use explicit, human-readable names. In particular, the
Transcript card displays **Review Required** instead of exposing the internal
`reviewRequired` identifier.

## Explicit render start

Approving a transcript still continues automatically through alignment because
that step requires no additional choice. Once alignment finishes, Podcast
Visualizer now waits at the aligned stage. The user starts rendering with
**Render Selected Outputs** after confirming the desired formats and branding.

This change does not alter immutable transcript, alignment, scene, or prior
render artifacts. Pending branding changes are still saved before a manually
started render.

## Distribution

The app remains self-contained for Apple Silicon Macs running macOS 15 or
later. Media, transcripts, model inputs, and review data stay on the Mac. The
GitHub release includes the signed and notarized app archive and DMG, signed
Sparkle metadata and delta update, checksums, SBOM, build metadata,
notarization evidence, and build provenance.
