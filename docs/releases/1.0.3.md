# Podcast Visualizer 1.0.3

Podcast Visualizer 1.0.3 restores model setup in signed release builds. It does
not change project, transcript, render, or model formats.

## Fixes

- The Project tab now includes a **Models** section that checks Parakeet and
  English alignment status inside the signed app's sandbox.
- **Locate & Import…** lets users select an existing pinned model directory.
  The app holds the user-approved security scope while the existing verifier
  checks the exact model files, rejects symlinks and unsafe paths, and copies
  only verified files into persistent app-owned storage.
- Prepared projects now stop at **Import Parakeet to Continue** instead of
  launching transcription with a missing release model. Approved projects use
  the equivalent alignment-model gate.
- Development builds can still reuse the repository's exact `models/`
  installation, but signed releases no longer appear ready solely because that
  development-only directory exists.

## Updating and one-time model setup

After updating, open **Models**, choose **Locate & Import…** next to Parakeet
v3, and select the existing `parakeet-tdt-0.6b-v3` directory. Select the
existing `whisperx-en` directory for English alignment in the same way. Large
imports may take several minutes because every pinned file is verified and
copied once. The imported copies remain available across later Sparkle updates.

- Apple Silicon Mac
- macOS 15.0 or later
- Existing verified Parakeet and English alignment directories can be reused

Choose **Check for Updates…** in Podcast Visualizer 1.0.2 to install the signed
1.0.3 update, or install the notarized DMG from GitHub Releases. Sparkle uses a
signed binary delta from the checksum-verified 1.0.2 ZIP when applicable and
falls back to the signed full ZIP.

Podcast media, transcripts, model inputs, and review data remain on the Mac.
Release assets include checksums, an SBOM, artifact-size evidence, build
metadata, notarization evidence, and GitHub build provenance.
