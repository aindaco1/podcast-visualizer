# Podcast Visualizer 1.3.5

Status: prepared. Publication, downloaded-artifact verification and installed
updater acceptance are separate release gates.

The app uses Platform's shared Sparkle controller and bounded reviewed-report
transport. Existing update settings, explicit report review and product-owned
diagnostic filtering remain in place. See the
[migration record](../SHARED_DESKTOP_MIGRATION.md) for characterization and rollback.

Since 1.3.4, the on-device chapter adviser also gained explicit topic-focus and
concise-title guidance. Development-only synthetic qualification is recorded in
the [chapter follow-up](../testing/chapter-quality-followup.md) and
[rubric evaluation](../testing/rubric-qualification-v2.md). These records include
judge disagreements and abstentions; they do not claim general podcast quality.

Native render tests now serialize shared AppKit window work while retaining both
delayed-content readiness and permanently blank-view failure checks. Real media,
transcripts and model inputs remain local. Jev is not bundled in the application.
