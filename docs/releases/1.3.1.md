# Podcast Visualizer 1.3.1

Status: released on 2026-09-07 from signed tag `v1.3.1`, source commit
`053f783db7ce1e923577cf787fecc005d2617e50`, and build 24.
[Download the notarized Apple Silicon DMG](https://github.com/aindaco1/podcast-visualizer/releases/download/v1.3.1/Podcast-Visualizer-1.3.1-arm64.dmg)
or review the [public release](https://github.com/aindaco1/podcast-visualizer/releases/tag/v1.3.1).

This maintenance release fixes Split at Playhead crashes caused by stale text
selections and rendering failures on transcripts containing pauses longer than
ten seconds. Failed and cancelled renders preserve the prior workflow stage,
aligned data, and existing outputs so rendering can be retried immediately.

Render diagnostics now retain selected options, the last output and phase,
bounded progress, helper exit details, and privacy-safe failure categories.
Recent native crash summaries can be reviewed alongside workflow failures.
**Report a Problem** shows the exact summary before **Send Reviewed Reports**
submits it to the shared Dust Wave relay. Similar reports update one GitHub
issue. Media, transcripts, model inputs, review data, file paths, and raw crash
reports remain local.

New speaker analyses count overlapping coverage once and keep ambiguous spans
available for review. Existing saved analyses are unchanged. Broader model
quality changes still require a local, representative benchmark.
