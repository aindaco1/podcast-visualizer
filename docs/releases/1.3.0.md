# Podcast Visualizer 1.3.0

Status: released on 2026-09-02 from signed tag `v1.3.0`, source commit
`717a17acbe0488032dfdf4604f8fad6906bb076f`, and build 23. Download the
[notarized Apple Silicon DMG](https://github.com/aindaco1/podcast-visualizer/releases/download/v1.3.0/Podcast-Visualizer-1.3.0-arm64.dmg)
or review the [complete public release](https://github.com/aindaco1/podcast-visualizer/releases/tag/v1.3.0).

Podcast Visualizer 1.3.0 makes long transcript review substantially faster
without changing the local-first media pipeline.

- Split a cue at the audio playhead and an explicit between-word text caret,
  with 150 ms edge protection, stable cue identity, one-step Undo, and no
  invented dialogue.
- Merge with either chronological neighbor. Cross-speaker merges fail closed as
  unconfirmed and ambiguous until reviewed.
- Review local Parakeet recognition confidence as Ultra Low, Low, Medium, High,
  or Unavailable; combine multiple tiers with the speaker and Unchecked filters
  without reordering the transcript.
- Mark cues Checked and preserve that progress through Save, quit, and relaunch
  for the current working copy. Checked state is excluded from approvals,
  transcript hashes, alignment, and renders, and resets for a new revision.
- See an Edited marker when confidence still describes original recognition
  evidence after human or structural changes.
- Rename speakers with Return, click-away, or speaker switching; the redundant
  Rename button is removed while Undo and explicit Save/Approve remain intact.

Confidence is an advisory triage signal, not proof of correctness. The UI does
not expose raw scores, does not reuse speaker confidence, and does not send
media, transcript, review, token, or model data off the Mac. The initial
aggregate-only calibration and its limits are documented in
[`../testing/1.3.0-confidence-calibration.md`](../testing/1.3.0-confidence-calibration.md).

The browser fallback remains compatible with native split/merge results but
does not have native interaction or confidence-filter parity in this release.
The bottom render waveform remains a separate future release.
