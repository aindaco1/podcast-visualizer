# Podcast Visualizer 1.1.1

Podcast Visualizer 1.1.1 makes first installation clearer while retaining the
same local-first application, runtime, model, project, transcript, and render
contracts.

## Simpler DMG installation

The notarized DMG now presents exactly one **Podcast Visualizer** app and an
Applications shortcut. Drag the app onto Applications, eject the image, and
launch the installed copy. The conventional single-app layout also works with
cautious automatic DMG handlers such as EasyDMG without making one a required
dependency.

The README links directly to the Apple Silicon DMG. The full GitHub release
continues to publish release notes, checksums, notarization evidence, build
metadata, artifact-size evidence, an SBOM, and provenance.

## Stronger release verification

Packaging and post-notarization validation share one exact DMG layout contract.
The release job verifies image integrity, mounts the final image read-only in a
private temporary location, rejects unexpected top-level entries or redirected
shortcuts, exercises the packaged CLI, and rechecks the app and DMG signatures,
stapled tickets, and Gatekeeper result before generating update metadata.

Failed validation stops publication and does not replace an existing release
artifact. No podcast media, transcripts, model inputs, review data, or project
outputs are involved in packaging or verification.
