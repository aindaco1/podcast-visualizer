# Podcast Visualizer 1.0.2

Podcast Visualizer 1.0.2 is a focused Transcript Review stability release.
It preserves the local-first, self-contained 1.0.1 runtime and does not change
project, transcript, render, or model formats.

## Fixes

- **Merge Next** now reconciles rows and applies edits by immutable cue ID. It
  removes only the immediately following cue, preserves every later line, and
  safely ignores delayed callbacks from a row that has already been removed.
- Approving an edited and saved transcript no longer risks a SwiftUI bounds
  trap while leaving Transcript Review. Both native and browser approval paths
  switch to the Project tab before clearing review state, and retained row
  callbacks become safe no-ops during teardown.
- **Check for Updates…** now appears in the top-right primary-action area of
  the window toolbar on both Project and Transcript Review tabs.

## Updating and requirements

- Apple Silicon Mac
- macOS 15.0 or later
- Existing verified local Parakeet and English alignment models remain valid

Choose **Check for Updates…** in Podcast Visualizer 1.0.1 to install the signed
1.0.2 update, or install the notarized DMG from GitHub Releases. Sparkle uses a
signed binary delta from the checksum-verified 1.0.1 ZIP when applicable and
falls back to the signed full ZIP.

Podcast media, transcripts, model inputs, review data, and immutable project
evidence remain on the Mac. Release assets include checksums, an SBOM,
artifact-size evidence, build metadata, notarization evidence, and GitHub
build provenance.
