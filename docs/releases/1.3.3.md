# Podcast Visualizer 1.3.3

Status: prepared on 2026-09-23. Publication, signed-artifact verification, and
installed-app acceptance are pending.

Native transcript approval preserves complete source sentence boundaries,
including questions and closing quotations. Apple's local sentence tokenizer
keeps abbreviations attached to their continuation. Unfinished phrases receive
optional Apple Intelligence advice in batches of six; incomplete or invalid
responses fall back safely. Words, acoustic speaker authority, timing limits,
review edits, and immutable revisions remain protected.

Speech and Apple generation infrastructure now come from the shared
Dust Wave Platform native package. Product policy stays in Podcast Visualizer.
FluidAudio remains pinned to 0.15.5; this release does not claim a new ASR model
or improved recognition accuracy. New runtime provenance binds the Platform
revision while validating older Record-backed runtimes.

Developer-only Jev evaluation uses hash-allowlisted synthetic text. Real audio,
transcripts, and review data stay on the Mac. The app contains no Jev provider
or credentials. See [the evaluation guide](../testing/jev-evaluation.md) and
[shared migration contract](../shared-native-migration.md).

## Validation and limits

- The unchanged 31-case Jev baseline passed after the shared migration: all
  fourteen controls and seventeen generated/local candidates passed, with no
  missing native evidence or exact-check failures.
- Local synthetic two-voice transcription produced identical transcript text,
  words, token timings, confidence, and speaker turns with the released 1.3.2
  helper and migrated helper. Both misrecognized “quieter” as “choir”; review is
  still necessary. Source audio hashes remained unchanged. The baseline used
  an ad-hoc-signed copy because the installed helper requires the app sandbox.
  This comparison is not signed-app acceptance or a speed benchmark.
- Release delta base: the verified public 1.3.2 ZIP, SHA-256
  `e81d7597166375ceca0892ba9d9357bca03126cd400422893130dbdfa0233213`.
- Final expanded Jev run: 22/22 actual candidates passed; all exact checks
  passed and native capture was complete. Fifteen of sixteen controls matched;
  the deliberately combined-sentence control was routed to review (fail 0.53,
  pass 0.45, uncertain 0.02). Inspection confirms that control is bad. The suite
  correctly remains exit 1, not an all-pass judge result. Questions and the
  0.10 margin were not weakened. Exact grouping regressions now catch a split
  abbreviation even when the judge approves it. This known judge limitation
  does not block this release's independently tested grouping policy.
- Local checks: 217 Node tests passed (two opt-in tests skipped), 130 Swift app
  tests, one sidecar progress test, 27 Python tests, dependency audit, workflow
  lint, and source whitespace checks passed. The Python gate used a fresh locked
  environment after the old editable development environment failed collection.
- Signing/notarization, hosted exact-commit CI, public assets, and installed-app
  checks will be recorded here as they complete.
