# Podcast Visualizer 1.0.1 size and update audit

Measured on Apple Silicon macOS on 2026-08-08. Private media and project paths
are intentionally omitted. The final protected release workflow records the
published values in `ARTIFACT-SIZES.json` and fails closed if a budget is
exceeded.

## Baseline and result

| Item | 1.0.0 baseline | 1.0.1 local candidate | Change |
| --- | ---: | ---: | ---: |
| Alignment runtime, logical bytes | 979,430,596 | 432,648,430 | -55.8% |
| Alignment runtime files | 31,364 | 7,097 | -77.4% |
| Node executable, logical bytes | 121,306,800 | 96,456,240 | -20.5% |
| App, allocated size | about 1.18 GiB | 606.6 MiB signed | about -49.8% |
| Full Sparkle ZIP, bytes | 381,771,149 | 189,170,052 | -50.4% |
| DMG, bytes | 609,877,439 | 225,639,872 | -63.0% |
| 1.0.0-to-1.0.1 Sparkle delta, bytes | none | 1,162,888 | n/a |

The Swift release binary is compiled with debug information disabled because
Xcode 26.3's `strip` rejects its fresh linker layout; Node is stripped before
its optimized manifest is sealed. The candidate ZIP used zlib level 9. The
candidate DMG used ULFO/LZFSE. The
final notarized bytes may differ slightly due to timestamped Developer ID
signatures and notarization tickets; the release budgets provide substantial
headroom without relaxing the measured result.

## Runtime policy and evidence

The optimized runtime is derived into a new directory from the exact pinned
`v0.1.0-rc.3` release payload after its published archive hash, release
contract, source manifests, runtime tree, and model tree validate. The source
tree is never edited in place.

The production-only alignment tree retains WhisperX forced alignment,
Wav2Vec2, Torch, torchaudio, Transformers, pandas, NumPy, NLTK English
`punkt_tab`, their production dependency closure, licenses, and offline socket
policy. It removes development packages, package tests, bytecode caches,
headers and compiler tooling, non-English tokenizers, unused Transformer model
implementations, and WhisperX ASR/diarization-only dependencies. A strict v2
manifest binds the optimized tree and its parent manifest.

After Developer ID signing changes Mach-O bytes, the release process reseals
FFmpeg, Node, speech, and alignment manifests as signed versions with explicit
parent hashes. A temporary ad-hoc copy of the verified packaged Node binary is
used only for release validation because the shipped Node carries sandbox
inheritance and JIT entitlements. The final local signing audit verified 121
nested CLI Mach-O files, the reviewed app and Node entitlements, and the exact
Developer ID team.

The prior full update is downloaded only from the GitHub release, must match
SHA-256
`5559a847860a60aec53d4d7efb47229eb71d0c60ad916c7e047c2df81a3a97a0`,
and is used to generate one signed LZFSE Sparkle delta. The appcast retains one
current version and one delta; the full ZIP remains the fallback.

## Enforced release ceilings

| Artifact | Ceiling |
| --- | ---: |
| Installed app | 850,000 KiB allocated |
| Full update ZIP | 355,000,000 bytes |
| DMG | 510,000,000 bytes |
| Sparkle delta | 250,000,000 bytes and smaller than the ZIP |

`scripts/release/validate-size-budget.mjs` records only artifact names and
sizes, rejects symlinks and missing or duplicate deltas, refuses to replace
existing evidence, and contains no absolute paths. Checksums and GitHub build
provenance include the size evidence and delta.
