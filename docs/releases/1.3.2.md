# Podcast Visualizer 1.3.2

Status: prepared for signed tag `v1.3.2`; publication and installed-updater
acceptance are pending.

Click between words in Transcript Review to move the playhead and pause audio,
then use **Split at Playhead**. The position is estimated from the caret's
location within the cue; use the audio controls to fine-tune before splitting.
Review cue timing does not provide verified word-to-text alignment.

Typing, Find, keyboard navigation, and drag selection leave playback alone.
Repeated clicks at the same caret still reposition the playhead after a manual
transport adjustment. Navigation preserves transcript text, cue timing, Checked
state, and existing approved revisions, alignment, and renders. Missing audio
explains how to save edits and reopen the project safely.

The native click observer retains the existing SwiftUI text editor and exact
text-snapshot selection safeguards. It waits for AppKit text tracking to finish,
accepts events only within its text box, and cancels deferred clicks on teardown.
No review schema, model, shared-package revision, or media pipeline changes are
required.
