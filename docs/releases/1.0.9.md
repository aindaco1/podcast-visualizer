# Podcast Visualizer 1.0.9

Podcast Visualizer 1.0.9 improves transcript reapproval reliability and
capitalizes rendered dialogue at sentence boundaries while preserving the
approved transcript, alignment, timing, and every existing output.

## Reliable transcript reapproval

Approving an unchanged active transcript is now an idempotent success. The app
reuses the existing immutable revision instead of attempting to recreate it,
which prevents the approval failure previously seen after editing, saving, and
approving again.

Transcript save and approval failures now provide privacy-safe recovery guidance
that explains what the user can do next and explicitly confirms that project
media, transcript revisions, and prior outputs were preserved.

## Sentence capitalization in rendered video

The display-only readability pass now capitalizes lower-case sentence starts
after periods, question marks, and exclamation points, as well as transcript
starts and speaker changes. It preserves acronyms and mixed-case terms such as
product names.

Capitalization never changes approved source text, speaker assignment, word
order, alignment, or timing. Each display-only change is recorded in the
scene's hash-bound readability evidence and validated before rendering.

## Privacy and distribution

All transcript, media, alignment, and rendering work remains local to the Mac.
The GitHub release includes the signed and notarized archive and DMG, signed
Sparkle metadata and delta update, checksums, SBOM, build metadata,
notarization evidence, artifact-size evidence, and build provenance.
