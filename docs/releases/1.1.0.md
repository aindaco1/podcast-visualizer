# Podcast Visualizer 1.1.0

Podcast Visualizer 1.1.0 makes rendered dialogue larger and moves it to a
stable center-frame reading region across landscape, square, and vertical
video, while preserving approved transcript and timing evidence.

## Larger, centered dialogue

Dialogue type is now 108 px at 1920×1080, 96 px at 1080×1080, and 94 px at
1080×1920. Cues use a center anchor with only a subtle vertical speaker shift,
so the reading position stays predictable during conversation.

Measured line planning reserves contrast-plate padding inside each aspect's
safe width. Both dialogue and its translucent plate are validated against safe
margins on every side, with at most two lines per cue. Speaker labels retain
the centered layout instead of resetting the ASS alignment style.

The new `transcript-video-scene-v5`, `dust-branded-v4`, and `ass-scene-v7`
identities keep existing scenes and renders immutable. Approved words, speaker
assignments, alignment, karaoke timing, and prior outputs are unchanged.

## Roadmap

The repository now records the next planned visual addition: a simple local,
audio-synchronized waveform along the bottom safe area. The waveform is not
included in this release.

## Privacy and distribution

All transcript, media, alignment, and rendering work remains local to the Mac.
The GitHub release includes the signed and notarized archive and DMG, signed
Sparkle metadata and delta update, checksums, SBOM, build metadata,
notarization evidence, artifact-size evidence, and build provenance.
