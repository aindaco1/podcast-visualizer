# Podcast Visualizer 1.0.1

Podcast Visualizer 1.0.1 makes transcript review more forgiving, makes the
default output choices immediately useful, and cuts the self-contained app and
update download roughly in half without adding local dependencies or moving
private data off the Mac.

## Highlights

- Transcript drafts conservatively format spoken English years such as
  “twenty twenty four,” capitalize standalone “I” and its contractions, and
  capitalize clear sentence starts. Raw Parakeet words and timings remain
  immutable analysis evidence.
- Cue grouping now rebalances preventable one-word tails while respecting
  speaker turns, pauses, timing, duration, and readability limits.
- **Edit Transcript** reopens an approved, aligned, rendered, verified, or
  exported transcript as a new working revision. Approval creates an immutable
  child revision; earlier transcripts, alignments, renders, and outputs remain
  unchanged.
- Transcript Review can navigate literal character, word, and phrase matches,
  wrap Previous/Next with Command-G and Shift-Command-G, visibly select the
  current result, replace that result, or replace all results with identical
  case and whole-word rules.
- New sessions select Landscape 16:9, Opaque H.264, and Compact HEVC Alpha by
  default. Square, Vertical, and ProRes 4444 Alpha remain available.
- **Check for Updates…** is now always available in the leading top-left window
  toolbar on both Project and Transcript Review tabs.

## Smaller, still self-contained

The release carries a verified production-only alignment runtime instead of
WhisperX features the app never invokes. It still bundles Node, FFmpeg,
CPython, Torch, torchaudio, Transformers, WhisperX forced alignment, fonts,
the speech sidecar, and diarization resources. It does not require Homebrew,
ambient `PATH`, system Python, system Node, or system FFmpeg.

Local candidate measurements reduced the full Sparkle ZIP from 381,771,149 to
189,170,052 bytes and the DMG from 609,877,439 to 225,639,872 bytes. The signed
1.0.0-to-1.0.1 Sparkle delta measured 1,162,888 bytes. Final published sizes
are recorded in `ARTIFACT-SIZES.json` and protected by release ceilings.

## Requirements and updating

- Apple Silicon Mac
- macOS 15.0 or later
- A verified local Parakeet v3 Core ML model
- The pinned English alignment model, imported or explicitly downloaded in the
  app

From Podcast Visualizer 1.0.0, choose **Podcast Visualizer → Check for
Updates…**. After installing 1.0.1, the action appears in the top-left toolbar.
The signed full ZIP remains a fallback if the signed binary delta is not
applicable. You can also install the notarized DMG from GitHub Releases.

Podcast media, transcripts, model inputs, review data, and project evidence
remain on the Mac. Model downloads are never implicit. Release assets include
checksums, an SBOM, artifact-size evidence, build metadata, notarization
evidence, and GitHub build provenance.
