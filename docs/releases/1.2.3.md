# Podcast Visualizer 1.2.3

Podcast Visualizer 1.2.3 shortens signed release builds while preserving the
same local-first app, runtime, updater, and distribution contracts.

## Verified build reuse

The required `main` CI job builds and validates the unsigned app once. Release
accepts only that exact commit's successful, GitHub-attested hosted-runner
artifact after checking its workflow identity, source ref, commit, Xcode
version, build inputs, Record submodule revision, executable and runtime
hashes, and constrained archive structure.

Only the version and build fields change before the existing fresh release
stages. Developer ID signing, Apple notarization and stapling, ZIP/DMG
packaging, mounted-DMG verification, Sparkle feed and binary delta generation,
size budgets, checksums, SBOM, provenance attestation, and publication remain
required.

## Privacy and compatibility

The application payload and user workflows are unchanged. Media, transcripts,
models, review data, projects, and renders stay on the Mac and are not included
in CI handoff metadata. Automatic update checks remain silent when current,
installation remains user approved, and **Check for Updates…** remains
available. The updater delta is generated from the verified 1.2.2 archive.
